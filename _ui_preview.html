行排查什么
决策mod 当前认为"该连哪台"以及走的是哪条分支（多数派 / 跟随房主 / 盲连）。现在完全看不到，出问题时最想知道的就是这个

语音房「语音房实际人数」对「分类判定人数」——两个口径不一致就是判定漂移，历史上那些自相矛盾都从这来
房间码 / 语音房名语音房名应该永远是"房间码_voice_"。不一致 = 语音还挂在上一个房间（同区连错服的一种成因）
强制区服 / 测速缓存这次找到分叉根因就靠这两条：游戏缓存 eu、语音缓存 ussc。不一致时语音那侧标黄
版本混装诊断。修好区服绑定后，别人装旧版是唯一剩下的分叉源
另一个思路：这些全部无条件塞进 Alt+J 控制台的「区服状态」按钮（那里空间无限，已经有一部分了），面板只留你选的几行。
